02. Shared Contracts, Preload Bridge & Signaling Code

Walkthrough of electron.vite.config.ts (p2pCsp), the 22 IPC channel registry, wire protocol schemas, contextBridge isolation, dynamic group ownership, and the standalone WebSocket signaling service.

1. Build & Bundler Configuration (electron.vite.config.ts)

electron.vite.config.ts controls multi-target bundling across Electron's three processes: 

export default defineConfig(({ command }) => {
  const isDev = command === 'serve'
  return {
    main: { build: { rollupOptions: { output: { format: 'es', entryFileNames: 'index.js' } } } },
    preload: { build: { rollupOptions: { output: { format: 'cjs', entryFileNames: 'index.cjs' } } } },
    renderer: {
      plugins: [react(), p2pCsp(isDev)],
      server: { host: '127.0.0.1', port: 5173, strictPort: true }
    }
  }
})

1.1. p2pCsp(isDev) and %P2P_CSP% Injection

The custom Vite plugin replaces %P2P_CSP% in src/renderer/index.html:

  • Development: connect-src 'self' ws://127.0.0.1:5173 (enables Vite HMR).
  • Production: connect-src 'none' (strictly blocks all direct web requests from the Renderer).

3. Domain Types & Input Validators (src/shared/p2p.ts)

Key domain primitives include:

  • P2pErrorCode: 15 standardized error literals (INVALID_INPUT, AUTH_FAILED, FORBIDDEN, INVITATION_REQUIRED, GROUP_EXISTS, GROUP_FULL, etc.).
  • GroupKey: Canonical JSON tuple JSON.stringify([signalingUrl, groupId]).
  • CreateGroupOptions & JoinGroupOptions: Options for dynamic group creation and joining via compact invite codes or full V2 JSON.
  • validateInviteCode: Enforces base64url regex /^[A-Za-z0-9_-]{8,64}$/.
  • parseGroupInvitation: Transparently parses either a V2 JSON string or a short invite code.

4. Wire Protocol & Runtime Type Guards (src/shared/p2p-wire.ts)

WebRTC data channels for chunked transfers are labeled using: 

export function makeFileChannelLabelV2(groupId: string, transferId: string): string {
  return `p2p-multiple-groups-file-v2:${groupId}:${transferId}`
}

Signaling Schemas

ClientSignalingMessageV2 handles create-group, join-group, rotate-invite, and remove-member. ServerSignalingMessageV2 returns group-joined (with ownerPeerId and inviteCode), invite-rotated, and group-kicked.

6. Signaling Service & CLI Tools (services/signaling/*, scripts/create-invite.ts)

The standalone Node.js 24 WebSocket signaling service implements:

  • Dynamic Group Creation: Generates 32-byte ownerSecret credentials.
  • Constant-Time Verification: Uses crypto.timingSafeEqual to authorize owner actions.
  • Owner Auto-Reseeding: Allows reconnecting owners to automatically restore groups upon server restarts.
  • CLI Utility: npm run signal:invite -- --group-id=engineering-team --code-only prints short invite codes for rapid sharing.
