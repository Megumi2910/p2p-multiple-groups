04. React Renderer UI & Inquiry Test Q&A Bank

Walkthrough of the sandboxed React 19 UI, usePeerState hook, swarm aggregation, master 30+ code locator lookup table, and a 32-question comprehensive viva defense exam bank.

1. Renderer Bootstrap & State Hook

The Renderer executes in an isolated Chromium browser environment:

  • Declaration Merging in env.d.ts: Merges window.p2p: P2pApi into the global Window interface.
  • React 19 Root: Mounted via ReactDOM.createRoot with React.StrictMode in src/renderer/src/main.tsx.
  • usePeerState Custom Hook: Listens on window.p2p.p2p.onState with monotonic revision checking to prevent out-of-order state updates.

2. Application Shell & Functional Views

Key views in the React 19 desktop interface:

  • App.tsx: Top-level navigation, theme synchronization, and global shortcuts (Ctrl+K).
  • Network.tsx: Dynamic group creation, short invite code joining, owner badge, invite rotation, member removal, and active roster inspector.
  • Library.tsx: Local file management, background SHA-256 progress, and per-group sharing grants.
  • Search.tsx: Group-scoped search queries and multi-source swarm aggregation by ${sha256}:${size}.
  • Transfers.tsx: Real-time 16 KiB chunk transfer tracking, Direct vs. Relayed route indicators, and cancellation.
  • CommandPalette.tsx: Native HTML5 <dialog> modal for fast keyboard navigation.
