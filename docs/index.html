p2p-multiple-groups

An encrypted, multi-group, hybrid peer-to-peer file sharing system and signaling network built with Electron, React 19, TypeScript, and Werift pure Node.js WebRTC.

Node.js ≥24.12.0 React 19.3 Electron 44.4 TypeScript 5.9 Werift WebRTC
🚀 Get Started

System Architecture Overview

The system is partitioned into three decoupled execution domains: the Authoritative Signaling Layer, the Electron Main Process (P2P Engine & Host), and the Sandboxed React 19 Renderer (Desktop UI).
